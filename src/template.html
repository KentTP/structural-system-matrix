Weighted decision matrix · podium + basement schemes · BC Building Code 2024 / VBBL 2025

Every option sits on the same base: a reinforced-concrete podium at Level 1 over one level of parking basement. Only the structure above the podium changes, so the ratings compare the upper floors and how they load the podium, foundations and basement box. Rate each system 1 (worst) to 5 (best) per criterion, switch criteria on or off, weight the ones that matter, and add a cost rating. Defaults are Sense's engineering view for a Metro Vancouver site — edit anything.

    EMTC = encapsulated mass timber construction. Storeys are counted above grade, so the parking basement does not count but the podium level does. Every EMTC building must be sprinklered and floors carry a 2-hour fire-resistance rating. Steel columns or steel-stud walls used with CLT floors are non-combustible construction and may be combined with EMTC in the same building (3.2.2.93.(2)). Confirm the applicable edition, occupancy mix and any alternative solutions with the authority having jurisdiction and a code consultant before relying on these tiers.
